Short description of this AI Agent From Rami: 

1. Search the web, visit links, and return scrapted text mentoning in 2026.
2. Check if research includes 2026 news and links.
3. Check if the linkedin post is clean by three conditions:
   - If total number of words are below 50, then the post is short, and add more details.
   - If there is no question in the post, add a question in the end.
   - If there is no # in the post, add 3 hashtags at the bottom.
